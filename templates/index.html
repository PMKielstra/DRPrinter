DRP Applications-to-PDF Renderer

This site renders CSV files, directly exported from Google Forms, to PDFs for easy printing and matching. It’s largely for the use of DRP organizers. If you want to apply for the Berkeley math DRP, you should go here instead.

The first row is automatically assumed to be the header row. Rows for the applicants are numbered starting at 2. If there’s a column you want to skip in the PDF but keep in the CSV (email address or name, for example), put a single hyphen character (“-”) at the beginning of the cell which gives that column its title. In other words, columns with titles that start with hyphens do not appear in the output PDF.
